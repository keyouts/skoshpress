BASICS & SHORTCUTS

The essentials for working in Skosh Press. On Mac, use Command in place of Ctrl.

PROJECTS

Use New to start, Open to load a project, and Save to keep your edits. Templates provide ready-made layouts. Import DOCX / TXT adds a manuscript.

PAGES & OBJECTS

Use + Page to add a page. Select pages on the left. Add a Text frame or Place image, then select an object to edit its settings on the right. Drag the object handle to move it; drag the corner handle to resize it. Double-click a text frame to edit its contents.

LAYOUT & EXPORT

Set page size, margins, guides and publication details in Inspector → Document. Use Check document to find layout issues, Print Studio for sheet and booklet planning, and Export PDF or Export formats to create files. Focus provides a smaller editing toolbar.

PRIVACY POLICY

Skosh Press · KeyOuts
Effective October 11, 2026.

DATA COLLECTION

Skosh Press does not require an account or collect usage data. It has no ads, analytics or automatic crash reporting.

LOCAL FILES

Projects, imports and exports are handled on your computer. The app does not upload your work. You choose where to save files. Preferences, templates, printer profiles, dictionaries and recovery data may be kept in local application storage.

INTERNET & SHARING

Publishing tools work offline. There is no cloud sync or automatic updater. If you share an exported file through another service, that service's privacy terms apply.

REMOVING DATA

Delete saved files where you stored them. Local settings or recovery files may remain after uninstalling; remove the application's data folder to clear them.

POLICY CHANGES

Changes to this policy will be included with a software release.
